- 菜单风格一致；“仅在 Codex 窗口内”和“整个桌面自由拖动”两种模式。
- “始终置顶”仅桌面模式显示，窗口模式隐藏并禁用；两种模式分别保存位置。
- 启动时等待 Codex 主界面就绪后显示挂件。

- 标准 MIT 代码许可、独立角色素材说明及完整贡献者 PR/Issue 记录，不按贡献量排名。
- 根 README 的“致谢与许可”和“交互参考”标记被发布脚本用于提取致谢，修改时须同步脚本。
